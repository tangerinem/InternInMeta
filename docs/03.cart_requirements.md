## 📝 고객 요구사항 정리
- 장바구니 총 금액이 10만원 미만 -> 배송비 3000원 추가
- 장바구니 총 금액이 10만원 이상 -> 배송비 무료

- 결제 모듈을 모달로 사용할 수 있도록 연동
- 뒤로가기 버튼을 누르면 메인 상품 목록 페이지로 이동

- 총 금액 계산

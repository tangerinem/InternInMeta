# 쇼핑몰 연동

## 프로젝트 개요

- 프로젝트 목표와 주요 기능에 대한 간략한 설명 : 상품 목록, 상세, 결제 페이지를 연동, 데이터 일관성을 유지한 쇼핑몰 
- 참여한 팀원 : 김민재

## 개발 환경

사용한 프레임워크, 라이브러리, 언어 등
> React 17.0, JavaScript ES6

## 설치 및 실행 방법

프로젝트를 로컬에서 실행하기 위한 설치 방법과 명령어

```
npm install
npm start
```

## 프로젝트 구조

## 주요 함수와 기능
- ProductList : 전체 상품 목록을 표시
- ProductDetail : 개별 상품의 상세 정보와 같은 브랜드의 관련 상품을 표시
- PayCompleted : 결제 완료 후 총 결제 금액을 보여주고, 상품 목록으로 이동할 수 있는 버튼

테스트 케이스 및 실행 방법

